## 3. Objectif

Ce document définit la consolidation par transformation, mécanisme central du Méthode Chatito permettant de renforcer une connaissance en demandant à l'apprenant de la mobiliser à travers différentes formes, structures, relations ou contextes.

Il répond à la question :

**Comment transformer une connaissance déjà étudiée afin de vérifier, renforcer et étendre sa maîtrise ?**

MC-004 ne définit pas les transformations propres à une langue. Il définit le mécanisme pédagogique permettant d'exploiter ces transformations. Les transformations disponibles sont déterminées par l'architecture linguistique correspondante.

## 4. Portée

MC-004 définit :

- le concept de transformation pédagogique ;
- la relation entre une connaissance et ses transformations ;
- la progression des transformations ;
- la sélection des transformations ;
- les transformations contrôlées, guidées et autonomes ;
- les transformations inverses ;
- les chaînes de transformations ;
- les transformations croisées ;
- la gestion de la complexité ;
- l'utilisation des transformations comme preuves de consolidation ;
- l'interaction avec MC-001, MC-002, MC-005 et MC-006 ;
- l'application du mécanisme à différentes langues.

MC-004 ne définit pas :

- les connaissances linguistiques elles-mêmes → architecture de la langue ;
- la structure générale d'une leçon → MC-001 ;
- l'évaluation et le diagnostic → MC-002 ;
- la gestion du vocabulaire → MC-005 ;
- la révision continue → MC-006 ;
- la phonétique et la prononciation → MC-008 ;
- la procédure d'analyse d'une nouvelle langue → LG-000.

## 5. Principe fondamental

Le Méthode Chatito considère qu'une connaissance ne doit pas être considérée comme consolidée uniquement parce que l'apprenant peut la reproduire sous la forme dans laquelle elle a été initialement présentée. La transformation permet de déplacer cette connaissance.

```
Connaissance → Forme initiale → Transformation → Nouvelle forme → Nouvelle transformation → Nouvelle utilisation
```

Plusieurs transformations permettent ainsi d'observer si l'apprenant possède réellement la connaissance ou s'il reproduit uniquement un modèle mémorisé.

## 6. Définition de la transformation pédagogique

Une transformation pédagogique est une opération dans laquelle l'apprenant reçoit une structure, une production ou une connaissance sous une certaine configuration et doit produire une configuration différente tout en maintenant les éléments pertinents de la connaissance travaillée.

Formellement : **État A → Transformation T → État B**

La transformation peut modifier certains éléments tout en maintenant d'autres invariants :

```
Structure initiale
├── éléments conservés
├── éléments transformés
└── éléments nouvellement produits
```

La nature exacte de ces éléments dépend de l'architecture de la langue.

## 7. Séparation entre connaissance et transformation

Ce document applique directement le **Principe 8 de MC-000** (séparation déclarative/procédurale) : *l'architecture linguistique* définit la connaissance ; *le Méthode Chatito* définit la transformation pédagogique qui l'exploite.

Par exemple, une architecture linguistique peut contenir une connaissance correspondant à une forme verbale particulière. MC-004 ne doit pas savoir intrinsèquement ce qu'est cette forme — il sait uniquement qu'une transformation définie par l'architecture peut être appliquée à cette connaissance.

**La langue définit ce qui peut être transformé ; MC-004 définit comment utiliser cette transformation pour consolider l'apprentissage.**

## 8. Relation avec l'architecture linguistique

Les types et les relations transformationnelles ne sont pas définis par MC-004 — ils appartiennent à l'architecture de chaque langue :

- **FR-660** → transformations disponibles en français
- **EN-660** → transformations disponibles en anglais
- **KO-660** → transformations disponibles en coréen

MC-004 fournit le mécanisme commun permettant de les exploiter. Cette séparation empêche le Méthode Chatito de devenir dépendant d'une langue particulière.

## 9. Unité transformationnelle

Toute transformation doit pouvoir être identifiée par au minimum :

```
Transformation
│
├── Entrée
├── Opération
├── Invariants
├── Éléments modifiés
├── Sortie attendue
├── Prérequis
└── Complexité
```

Cette représentation permet à une transformation d'être utilisée indépendamment de la langue.

## 10. Cycle de transformation

```
Présentation → Transformation contrôlée → Observation
→ Transformation guidée → Observation
→ Transformation autonome → Observation
→ Transformation inverse → Évaluation
→ Consolidation ou intervention
```

Ce cycle n'est pas nécessairement exécuté entièrement à chaque fois. MC-002 détermine, selon les évidences disponibles, le niveau d'intervention nécessaire.

## 11. Sélection de la transformation

MC-004 ne choisit pas arbitrairement une transformation. La sélection dépend de : la connaissance actuellement travaillée, ses prérequis, les relations disponibles dans l'architecture linguistique, l'état d'acquisition déterminé par MC-002, la difficulté observée, la complexité cognitive de la tâche, et l'objectif de consolidation.

```
MC-002 (difficulté détectée) → Transformation pertinente → MC-004
```

MC-004 ne remplace donc pas le diagnostic de MC-002.

## 12. Transformation contrôlée

Dans une transformation contrôlée, les paramètres sont fortement définis (*« Transforme A selon T. »*). L'objectif est de vérifier si l'apprenant peut appliquer une relation connue sans ajouter inutilement d'autres difficultés. La transformation contrôlée constitue généralement le niveau initial.

## 13. Transformation guidée

La transformation guidée réduit progressivement les supports :

```
Support élevé → Support partiel → Support minimal
```

L'apprenant doit progressivement reconstruire la relation sans dépendre du modèle initial.

## 14. Transformation autonome

Dans une transformation autonome, l'apprenant doit déterminer lui-même la manière d'appliquer la relation (*« Produisez une nouvelle formulation conservant le même sens selon la relation demandée. »*). La difficulté ne réside alors plus uniquement dans l'application d'une règle, mais dans la mobilisation autonome de la connaissance.

## 15. Transformation inverse

Une transformation peut être pratiquée dans les deux directions : A → B et B → A. Elle est importante car elle permet de vérifier que l'apprenant maîtrise la relation elle-même plutôt qu'une seule procédure mémorisée.

## 16. Chaînage transformationnel

Plusieurs transformations peuvent être enchaînées (A → B → C → D → E), chaque étape ajoutant une nouvelle contrainte.

Un exemple d'application au français pourrait être :

```
Présent → Passé composé → Imparfait → Futur → Conditionnel
```

Cet exemple appartient à l'architecture et à la pratique du français ; il ne constitue pas une structure universelle de MC-004. Une autre langue peut posséder une chaîne complètement différente.

## 17. Transformations croisées

Une transformation peut mobiliser plusieurs connaissances simultanément — grammaticale, syntaxique, lexicale, discursive. Cette combinaison permet d'observer la capacité de l'apprenant à mobiliser plusieurs connaissances dans une même opération.

Cependant, une difficulté dans une transformation croisée ne doit pas automatiquement être attribuée à toutes les connaissances mobilisées — MC-002 doit déterminer la source probable de la difficulté.

## 18. Complexité transformationnelle

La complexité peut augmenter progressivement selon plusieurs dimensions : nombre de contraintes, nombre de connaissances mobilisées, distance entre entrée et sortie, réduction du support, autonomie demandée, variété du contexte.

Une transformation complexe n'est donc pas nécessairement meilleure qu'une transformation simple. Le niveau de complexité doit être proportionnel à l'état d'acquisition de l'apprenant.

## 19. Transformation et consolidation

La transformation devient un mécanisme de consolidation lorsqu'elle permet de démontrer que l'apprenant peut maintenir une connaissance tout en modifiant sa configuration. Une seule transformation réussie ne suffit pas nécessairement — la consolidation est renforcée lorsque l'apprenant démontre stabilité, flexibilité, autonomie, capacité à transformer dans plusieurs directions, capacité à mobiliser la connaissance dans différents contextes, et capacité à combiner plusieurs transformations.

## 20. Production de nouvelles évidences

```
Transformation → Production → Observation → MC-002 → Diagnostic
```

Une transformation n'est donc pas uniquement un exercice — elle constitue également un instrument d'observation de la maîtrise.

## 21. Interaction avec MC-002

MC-002 détermine l'état de la connaissance et identifie les difficultés persistantes. MC-004 fournit le mécanisme permettant de produire des transformations ciblées.

```
MC-002 (difficulté identifiée) → MC-004 (transformation ciblée) → nouvelle production → MC-002
```

MC-004 n'a donc pas besoin de déterminer lui-même si une connaissance doit être réenseignée.

## 22. Interaction avec MC-001

MC-001 définit la structure standard d'une leçon ; la transformation constitue une étape de la leçon lorsque celle-ci est pertinente. MC-004 approfondit cette étape en définissant les mécanismes permettant de continuer la consolidation au-delà d'une seule leçon.

- MC-001 → transformation *dans* la leçon.
- MC-004 → système général de consolidation par transformation.

## 23. Interaction avec MC-005

Les transformations peuvent mobiliser du vocabulaire. MC-005 gère la sélection, le réemploi et le suivi du vocabulaire. MC-004 utilise ce vocabulaire comme matériau lorsqu'une transformation le nécessite, sans devenir lui-même un système de gestion lexicale.

## 24. Interaction avec MC-006

Une transformation peut être réactivée ultérieurement :

```
MC-004 (transformation) → évidence → MC-002 (état stable) → MC-006 (réactivation ultérieure)
```

MC-006 assure la continuité temporelle de la consolidation ; MC-004 fournit le mécanisme transformationnel pouvant être réutilisé lors de cette réactivation.

## 25. Architecture multi-langues

MC-004 est conçu pour fonctionner indépendamment de la langue :

```
MC-004
│
├── Français
├── English
├── 한국어
├── Deutsch
└── ...
```

Cependant, les transformations disponibles, leur structure et leur complexité peuvent varier considérablement selon la langue. Le Méthode Chatito ne doit donc jamais supposer qu'une transformation existante dans une langue existe nécessairement dans une autre.

## 26. Intégration avec LG-000

LG-000 définit le processus permettant d'analyser une nouvelle langue et de construire son architecture linguistique. Dans ce processus, LG-000 doit pouvoir identifier les relations transformationnelles pertinentes pour la langue étudiée.

```
LG-000 → analyse de la langue → architecture linguistique → relations transformationnelles → MC-004 → consolidation
```

MC-004 ne définit donc pas les transformations d'une langue. Il définit comment toute transformation correctement représentée par l'architecture linguistique peut devenir un mécanisme de consolidation.

## 27. Exemples d'application linguistique

Les exemples présentés dans cette section ont uniquement une fonction illustrative. Ils ne constituent pas une liste normative des transformations du Méthode Chatito.

**Français** — une architecture française peut définir une relation entre plusieurs formes temporelles :

```
Présent → Passé composé → Imparfait → Futur → Conditionnel
```

MC-004 exploite cette relation pour créer une séquence de consolidation.

**English** — une architecture anglaise peut définir des relations entre différentes formes verbales, par exemple :

```
Present → Past → Present Perfect → Present Perfect Continuous
```

Cette relation appartient à l'architecture anglaise. MC-004 ne contient aucune connaissance intrinsèque concernant le Present Perfect Continuous.

**Coréen** — une architecture coréenne peut définir des relations propres à la morphologie, aux niveaux de politesse, aux constructions syntaxiques ou à d'autres propriétés pertinentes de la langue. MC-004 peut exploiter ces relations sans modifier son mécanisme général.

## 28. Limites

La transformation ne doit pas être utilisée comme unique mécanisme pédagogique. Certaines connaissances peuvent nécessiter exposition, explication, reconnaissance, production, écoute, prononciation, mémorisation, réactivation, communication spontanée.

MC-004 constitue donc un mécanisme de consolidation parmi les mécanismes du Méthode Chatito. Sa fonction spécifique est de renforcer la flexibilité et la stabilité d'une connaissance par changement contrôlé de sa configuration.

## 29. Principe de non-mécanisation

La transformation ne doit jamais devenir une procédure mécanique appliquée systématiquement à chaque connaissance. Le Méthode Chatito ne doit pas produire *« Connaissance → toujours 10 transformations »*, mais :

```
Connaissance → État observé → Transformation pertinente → Nouvelle évidence → Décision pédagogique
```

Le nombre, le type, la direction et la complexité des transformations dépendent de la langue, de la connaissance, de l'architecture linguistique, de l'état de l'apprenant et du diagnostic pédagogique.

## 33. Glossaire

| Terme | Définition |
|---|---|
| Transformation | Opération faisant passer une connaissance ou une structure d'une configuration à une autre selon une relation définie. |
| Transformation pédagogique | Transformation utilisée intentionnellement pour observer ou renforcer une connaissance. |
| Consolidation | Stabilisation d'une connaissance permettant son utilisation flexible et durable. |
| Invariant | Élément qui doit rester inchangé pendant une transformation. |
| Transformation inverse | Transformation permettant de revenir de la sortie vers la configuration initiale. |
| Chaînage transformationnel | Succession de plusieurs transformations appliquées à une même séquence d'apprentissage. |
| Transformation croisée | Transformation mobilisant plusieurs connaissances simultanément. |
| Complexité transformationnelle | Niveau de difficulté résultant du nombre de contraintes, connaissances et opérations mobilisées. |
| Architecture linguistique | Organisation déclarative des connaissances propres à une langue. |
| Relation transformationnelle | Relation entre deux configurations linguistiques pouvant être exploitée pédagogiquement. |
| Évidence pédagogique | Observation permettant d'estimer l'état d'une connaissance. |
| LG-000 | Méthode générale permettant d'analyser une langue et de construire son architecture pour le Méthode Chatito. |
