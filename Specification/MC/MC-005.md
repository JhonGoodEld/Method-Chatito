## 3. Objectif

MC-005 définit la manière dont le Méthode Chatito gère le vocabulaire au cours de l'apprentissage. Il répond à la question :

**Quelle quantité de vocabulaire doit être introduite, dans quel ordre, à quelle fréquence et dans quels contextes doit-elle être réutilisée ?**

MC-005 ne définit pas le vocabulaire d'une langue. Il définit la politique pédagogique appliquée au vocabulaire. Le système doit notamment déterminer :

- quels éléments lexicaux doivent recevoir une priorité pédagogique ;
- combien de nouveaux éléments peuvent être introduits simultanément ;
- comment les nouveaux éléments sont réutilisés ;
- comment leur acquisition est observée ;
- comment les difficultés lexicales sont traitées ;
- comment le vocabulaire ancien est maintenu actif ;
- comment le vocabulaire est distribué dans le temps ;
- comment les besoins réels de communication peuvent modifier les priorités.

## 4. Portée

MC-005 définit : la sélection pédagogique du vocabulaire, la priorisation, la fréquence d'introduction, le volume lexical, la réutilisation, l'espacement, la consolidation, la distinction entre vocabulaire actif et passif, la gestion des difficultés lexicales, l'intégration du vocabulaire dans les leçons, l'adaptation de la charge lexicale, et la relation entre vocabulaire nouveau et vocabulaire déjà étudié.

MC-005 ne définit pas :

- quels mots existent dans une langue → architecture linguistique ;
- la fréquence lexicale elle-même → FR-320 ;
- les collocations → FR-340 ;
- la structure d'une leçon → MC-001 ;
- l'état d'acquisition → MC-002 ;
- les transformations → MC-004 ;
- la révision générale → MC-006.

## 5. Principe fondamental

Le Méthode Chatito considère le vocabulaire comme une ressource pédagogique distribuée dans le temps, et non comme une liste de mots à mémoriser indépendamment.

Le système cherche donc moins à répondre *« Combien de mots l'apprenant a-t-il vus ? »* qu'à répondre *« Quels éléments lexicaux l'apprenant peut-il réellement mobiliser lorsqu'il en a besoin ? »* La simple exposition à un mot ne constitue donc pas une preuve de maîtrise.

## 6. Séparation entre lexique et gestion lexicale

La séparation entre architecture linguistique et méthodologie (Principe 8 de MC-000) s'applique directement au vocabulaire.

```
FR-300
│
├── FR-320 Fréquence lexicale
├── FR-370 Formation lexicale
├── FR-340 Collocations
└── ...
        │
        ↓
     MC-005
        │
        ├── sélection
        ├── introduction
        ├── distribution
        ├── réemploi
        └── consolidation
```

FR-300 décrit ce qui existe. MC-005 décrit comment ce matériel lexical est géré pédagogiquement.

## 7. Sources lexicales

MC-005 peut recevoir des informations provenant de plusieurs branches de l'architecture linguistique.

| Source | Utilisation par MC-005 |
|---|---|
| FR-320 — Fréquence lexicale | Priorisation des éléments fréquents |
| FR-340 — Collocations | Réemploi d'unités lexicales combinées |
| FR-370 — Formation lexicale | Organisation des familles lexicales |
| FR-300 | Identification des éléments lexicaux |

La structure exacte de ces sources dépend de l'architecture de chaque langue. MC-005 ne doit donc pas supposer que toutes les langues organisent leur lexique de la même manière.

## 8. Priorisation du vocabulaire

Le Méthode Chatito privilégie initialement les éléments lexicaux présentant une forte valeur pédagogique. Cette valeur peut dépendre de : la fréquence, l'utilité communicative, la polyvalence, la présence dans les structures actuellement étudiées, la capacité de réutilisation, les besoins exprimés par l'apprenant, les difficultés observées dans les productions.

La fréquence constitue donc un facteur de priorité, mais ne constitue pas à elle seule la politique de sélection.

## 9. Fréquence lexicale

Lorsque l'architecture linguistique fournit des informations de fréquence, MC-005 peut les utiliser afin de favoriser l'introduction précoce des éléments les plus fréquents :

```
FR-320 (Fréquence) → MC-005 → Priorité pédagogique
```

Cette stratégie poursuit un objectif pragmatique : permettre à l'apprenant de percevoir rapidement une augmentation de sa capacité communicative. Un vocabulaire très fréquent offre davantage d'occasions de réemploi dans les premières productions.

Cependant, **fréquent ≠ automatiquement prioritaire**. Un élément moins fréquent peut devenir prioritaire lorsqu'il est nécessaire à une structure grammaticale étudiée, à une tâche communicative ou à un besoin exprimé par l'apprenant.

## 10. Utilité communicative

La sélection lexicale doit tenir compte de la capacité d'un élément à produire une amélioration réelle de la communication. Un mot peut être prioritaire parce qu'il permet de construire de nombreuses phrases, apparaît dans plusieurs contextes, complète une structure grammaticale étudiée, permet de résoudre un besoin communicatif immédiat, ou peut être réutilisé dans plusieurs transformations.

MC-005 doit donc rechercher une forte valeur de réutilisation, plutôt qu'une simple accumulation quantitative.

## 11. Volume lexical

MC-005 doit contrôler la quantité de vocabulaire nouveau introduite dans une séquence pédagogique. Le système doit éviter qu'une leçon grammaticale devienne simultanément une leçon massive de vocabulaire.

Une surcharge lexicale peut empêcher l'apprenant de distinguer **difficulté grammaticale ≠ difficulté lexicale**.

Le volume de vocabulaire nouveau doit donc être compatible avec la complexité de la connaissance grammaticale, la longueur de la leçon, les connaissances lexicales déjà disponibles, la capacité de réutilisation immédiate, et l'état d'apprentissage observé par MC-002.

## 12. Introduction du vocabulaire

Lorsqu'un nouvel élément lexical est introduit, MC-005 doit favoriser son apparition dans un contexte significatif. Le vocabulaire ne doit pas être systématiquement présenté comme *mot → traduction → mémorisation*, mais peut être intégré dans *mot → contexte → compréhension → utilisation → réutilisation*.

La forme exacte de présentation appartient cependant à MC-001. MC-005 détermine quels éléments doivent être disponibles pour cette présentation.

## 13. Réutilisation du vocabulaire

Un élément lexical nouvellement introduit doit pouvoir réapparaître dans des contextes ultérieurs :

```
Introduction → Utilisation guidée → Transformation → Production → Nouvelle leçon → Production spontanée
```

Le même élément peut ainsi être rencontré plusieurs fois sans que chaque occurrence soit traitée comme une nouvelle leçon lexicale.

## 14. Distribution et espacement

La réutilisation ne doit pas être concentrée exclusivement dans la leçon où le mot est introduit :

```
J0 → introduction · J1 → réemploi · J3 → réemploi · J7 → récupération · J14 → nouvelle utilisation
```

Les intervalles exacts ne sont pas imposés par MC-005 si ceux-ci relèvent du système général de révision défini par MC-006. **MC-005 définit le besoin de réactivation lexicale ; MC-006 définit le mécanisme général de révision.**

## 15. Consolidation lexicale

Un élément lexical ne doit pas être considéré comme consolidé simplement parce que l'apprenant peut en donner la traduction. La consolidation peut être observée lorsque l'apprenant peut : reconnaître l'élément, comprendre son utilisation, le produire, l'utiliser dans plusieurs contextes, l'associer à d'autres éléments, le mobiliser sans rappel explicite, le récupérer dans une production spontanée.

La distinction entre ces niveaux est compatible avec les états d'acquisition définis dans MC-002.

## 16. Vocabulaire actif et passif

- **Vocabulaire passif** — éléments que l'apprenant peut reconnaître ou comprendre lorsqu'il les rencontre.
- **Vocabulaire actif** — éléments que l'apprenant peut récupérer et utiliser dans sa propre production.

```
Reconnu → Compris → Produit avec support → Produit autonomement
```

MC-002 peut utiliser ces observations pour déterminer l'état d'acquisition.

## 17. Vocabulaire nouveau et connu

Une leçon ne doit pas considérer tout son vocabulaire comme nouveau :

```
Nouveau
├── Prioritaire
└── Secondaire

Connu
├── À maintenir
├── À réactiver
└── À consolider
```

Cette distinction permet de maintenir une proportion importante de vocabulaire déjà connu tout en introduisant progressivement de nouveaux éléments.

## 18. Réemploi contextuel

La répétition mécanique d'un même exemple ne constitue pas nécessairement une consolidation suffisante. MC-005 doit favoriser le changement de contexte :

```
même élément → contexte A → contexte B → contexte C → production autonome
```

Le but est de vérifier que l'apprenant a acquis un élément lexical utilisable, et non uniquement associé à une phrase particulière.

## 19. Gestion des difficultés lexicales

Une difficulté lexicale doit être distinguée des autres catégories d'erreurs définies dans MC-002. Elle peut concerner : la récupération du mot, le sens, la forme, le genre, le nombre, la prononciation, la combinaison avec d'autres mots, le registre, la confusion avec un autre élément lexical.

Le diagnostic appartient à MC-002. La gestion pédagogique du vocabulaire concerné appartient à MC-005.

## 20. Interaction avec MC-001

```
MC-005 (sélection lexicale) → MC-001 (intégration dans la leçon)
```

MC-001 ne doit donc pas décider indépendamment de la politique globale d'introduction du vocabulaire.

## 21. Interaction avec MC-002

```
Production → MC-002 (difficulté lexicale) → MC-005 (traitement lexical) → nouvelle production
```

MC-002 évalue. MC-005 gère.

## 22. Interaction avec MC-004

```
MC-004 (transformation → difficulté lexicale) → MC-005
```

MC-004 ne devient donc pas un gestionnaire lexical.

## 23. Interaction avec MC-006

```
MC-005 (éléments à réactiver) → MC-006 (révision) → MC-002 (nouvelle observation)
```

## 24. Interaction avec l'architecture linguistique

MC-005 doit toujours respecter la frontière entre catalogue linguistique et politique pédagogique.

- **FR-320** : *« X est fréquent. »* (architecture linguistique)
- **MC-005** : *« X reçoit donc une priorité pédagogique élevée, sous réserve des autres critères. »* (méthodologie)

## 25. Architecture multi-langues

MC-005 ne doit contenir aucune hypothèse structurelle propre au français. Le modèle doit pouvoir recevoir FR-300, KO-300, EN-300, etc., et appliquer la même logique méthodologique générale.

Cependant, les informations fournies par chaque architecture linguistique peuvent différer — listes de fréquence, familles morphologiques, unités lexicales complexes, systèmes de classificateurs, distinctions lexicales inexistantes dans une autre langue, catégories propres à son fonctionnement. MC-005 doit exploiter ces informations sans imposer leur existence dans toutes les langues.

Cette abstraction constitue une responsabilité future de LG-000.

## 26. Principe de priorité communicative

Le Méthode Chatito cherche à produire des gains communicatifs perceptibles relativement tôt dans l'apprentissage. Le vocabulaire fréquent et fortement réutilisable doit donc recevoir une priorité particulière.

Cependant, la vitesse d'apparition des résultats ne doit jamais être obtenue au prix d'une surcharge ou d'une progression artificielle. La priorité communicative doit rester compatible avec la consolidation.

## 27. Principe de réutilisation

```
Introduction → Réemploi → Variation → Réactivation → Production → Consolidation
```

La réutilisation constitue donc une propriété structurelle du parcours lexical et non une activité optionnelle.

## 28. Principe de non-surcharge lexicale

Le Méthode Chatito ne cherche pas à maximiser le nombre de mots introduits par leçon, mais à maximiser le nombre d'éléments réellement mobilisables par l'apprenant.

*10 mots introduits + réutilisés + compris + produits* peut représenter une progression plus utile que *30 mots introduits, rarement réutilisés.* Le volume lexical doit donc être subordonné à la capacité de consolidation.

## 29. Principe de progression adaptative

La politique lexicale n'est pas entièrement fixe. MC-005 peut adapter la sélection en fonction des connaissances déjà consolidées, des difficultés observées, des besoins communicatifs, des structures grammaticales étudiées, des demandes de l'apprenant, et du vocabulaire disponible dans l'architecture linguistique. Le système peut donc modifier la priorité sans modifier l'architecture linguistique elle-même.

## 30. Limites

MC-005 ne doit pas : devenir un dictionnaire ; définir la fréquence lexicale ; remplacer FR-300 ; remplacer MC-002 dans le diagnostic ; remplacer MC-006 dans la révision générale ; imposer une quantité universelle de vocabulaire à toutes les langues ; considérer la traduction comme preuve suffisante de maîtrise ; confondre exposition et acquisition ; confondre fréquence et priorité absolue.

## 34. Glossaire

| Terme | Définition |
|---|---|
| Élément lexical | Unité du lexique pouvant être mobilisée dans la compréhension ou la production. |
| Vocabulaire passif | Vocabulaire reconnu ou compris par l'apprenant. |
| Vocabulaire actif | Vocabulaire que l'apprenant peut récupérer et produire. |
| Fréquence lexicale | Mesure de la fréquence d'apparition d'un élément lexical dans une source ou un corpus. |
| Priorité lexicale | Importance pédagogique attribuée à un élément lexical. |
| Réemploi | Nouvelle utilisation d'un élément lexical précédemment rencontré. |
| Charge lexicale | Quantité et complexité du vocabulaire mobilisé dans une activité. |
| Consolidation lexicale | Stabilisation d'un élément lexical permettant sa récupération et son utilisation dans différents contextes. |
| Réactivation | Nouvelle mobilisation d'un élément lexical précédemment étudié. |
| Collocation | Association lexicalement privilégiée entre plusieurs éléments. |
| Vocabulaire nouveau | Éléments qui n'ont pas encore été suffisamment étudiés ou consolidés. |
| Valeur communicative | Capacité d'un élément à contribuer à la communication dans différents contextes. |
