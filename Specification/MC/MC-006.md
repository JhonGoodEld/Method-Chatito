## 3. Objectif

Ce document définit le mécanisme de Consolidation Continue du Méthode Chatito. Il répond à une question fondamentale :

**Comment maintenir accessibles, flexibles et mobilisables les connaissances déjà étudiées afin qu'elles ne disparaissent pas progressivement avec le temps ?**

MC-006 ne constitue pas une nouvelle méthode d'enseignement d'un contenu linguistique. Il définit les mécanismes permettant de sélectionner, réactiver, récupérer et remobiliser des connaissances précédemment étudiées.

```
Apprendre une connaissance → L'utiliser → La consolider → La réactiver ultérieurement
→ La réutiliser → Observer à nouveau sa maîtrise → Continuer ou adapter la consolidation
```

La consolidation n'est donc pas considérée comme une étape finale d'un apprentissage. Elle constitue un processus continu.

## 4. Portée

MC-006 définit : la consolidation continue, la sélection des connaissances à réactiver, les mécanismes de réactivation, la récupération de connaissances, la révision aléatoire, la révision par dépendance, la révision par erreurs fréquentes, la révision temporelle, la combinaison de plusieurs stratégies, la réutilisation des connaissances dans de nouveaux contextes, l'utilisation de l'historique pédagogique pour sélectionner les connaissances, et les relations entre consolidation et état du savoir.

MC-006 ne définit pas :

- les connaissances propres à une langue → architecture linguistique correspondante ;
- la structure d'une leçon → MC-001 ;
- l'état d'acquisition d'une connaissance → MC-002 ;
- les transformations comme mécanisme spécifique → MC-004 ;
- la gestion du vocabulaire → MC-005.

## 5. Principe fondamental

Le Méthode Chatito considère qu'une connaissance déjà étudiée ne doit pas être considérée comme définitivement acquise simplement parce qu'elle a été correctement utilisée pendant son enseignement initial.

Une connaissance peut être : correcte mais récente ; acquise mais instable ; consolidée ; temporairement moins accessible ; oubliée puis récupérée ; stable mais peu flexible ; flexible dans un contexte mais difficile à mobiliser dans un autre.

La consolidation continue vise donc à maintenir la connaissance accessible et utilisable dans le temps, et non simplement à augmenter le nombre de connaissances étudiées.

## 6. Pourquoi « Consolidation Continue » ?

Le terme *Révision Espacée* décrit uniquement une partie du mécanisme. L'espacement temporel constitue une stratégie utile, mais il ne représente pas l'ensemble du système. MC-006 utilise plusieurs sources permettant de déterminer quelles connaissances doivent être remobilisées :

```
MC-006 → hasard, dépendance, erreurs → temporelle
```

Le temps écoulé est donc une variable parmi plusieurs. Le terme *Consolidation Continue* décrit mieux le principe général : une connaissance continue à faire partie du processus d'apprentissage après son enseignement initial.

## 7. Séparation entre connaissance et mécanisme de consolidation

Ce document applique directement le **Principe 8 de MC-000** (séparation déclarative/procédurale). MC-006 ne doit contenir aucune connaissance propre à une langue.

Par exemple, *FR-500 → FR-530 → Indicatif → Présent* décrit une connaissance française. MC-006 ne définit pas ce qu'est le présent — il définit uniquement la possibilité de sélectionner cette connaissance pour une réactivation ultérieure.

```
Architecture linguistique → QUOI apprendre ? → FR-*/KO-*/EN-*
MC-006 → COMMENT maintenir cette connaissance ?
```

Cette séparation constitue une condition fondamentale de l'indépendance linguistique du Méthode Chatito.

## 8. Unité de consolidation

L'unité fondamentale de MC-006 est une connaissance identifiable dans l'architecture linguistique — par exemple *FR-531 — Indicatif présent*, ou, dans une autre langue, *KO-XXX — [connaissance correspondante]*.

MC-006 doit pouvoir recevoir une référence à cette connaissance sans avoir besoin de connaître sa nature linguistique. Une connaissance peut également être réactivée avec ses relations : prérequis, dépendances, connaissances associées, connaissances dépendantes.

## 9. Réactivation continue

La réactivation consiste à remettre une connaissance précédemment étudiée à la disposition de l'apprenant. Elle peut prendre différentes formes : rappel, récupération sans support, question, production, transformation, réutilisation lexicale, comparaison, production écrite, production orale, intégration dans une nouvelle leçon.

La réactivation ne doit donc pas nécessairement reproduire l'exercice original. Au contraire, la variation des contextes constitue une composante importante de la consolidation.

## 10. Stratégies de consolidation

MC-006 définit quatre stratégies principales : révision par hasard, révision par dépendance, révision par erreurs fréquentes, révision temporelle. Ces stratégies peuvent fonctionner individuellement ou être combinées. Aucune n'est considérée comme universellement suffisante.

## 11. Révision par hasard

La révision par hasard consiste à sélectionner aléatoirement une connaissance parmi un ensemble de connaissances précédemment étudiées, afin d'introduire une sélection non prévisible.

```
Connaissances disponibles : FR-531, FR-432, FR-561, FR-611, FR-721, FR-811 → 🎲 → FR-531
```

Cette stratégie empêche la révision de devenir entièrement dépendante de la séquence originale des leçons. **Principe :** une connaissance doit pouvoir être mobilisée même lorsque son apparition n'est pas annoncée.

## 12. Révision par dépendance

La révision par dépendance utilise l'architecture des connaissances pour réactiver des éléments nécessaires à une connaissance actuelle.

```
A → B → C
```

Si l'apprenant travaille sur C, MC-006 peut sélectionner A ou B afin de vérifier que les connaissances sous-jacentes restent accessibles. Cette stratégie exploite directement la structure de l'architecture linguistique, et est particulièrement importante lorsque les connaissances forment des chaînes ou des réseaux de dépendances.

## 13. Révision par erreurs fréquentes

MC-002 peut identifier une difficulté persistante (production 1, 2, 3 → même erreur X), et transmettre cette information à MC-006 :

```
MC-002 (difficulté persistante) → MC-006 (réactivation ciblée)
```

La connaissance concernée obtient alors une priorité supérieure dans la sélection future. Cette stratégie est fondée sur l'évidence pédagogique, et non uniquement sur le temps écoulé.

## 14. Révision temporelle

La révision temporelle utilise le temps écoulé depuis les dernières observations significatives d'une connaissance, et permet de réintroduire progressivement des connaissances anciennes. Le temps ne constitue toutefois pas une règle absolue — une sélection temporelle doit idéalement tenir compte de la date de dernière activation, l'état actuel, les observations précédentes, la fréquence d'utilisation, les erreurs récentes, et la stabilité historique.

```
Temps écoulé + Historique + État actuel + Évidences récentes → Priorité de réactivation
```

## 15. Combinaison des stratégies

Les quatre stratégies peuvent être combinées :

```
Connaissances disponibles → (dépendance, historique, erreurs, temporalité) → sélection → réactivation
```

Une connaissance peut donc être sélectionnée parce qu'elle a été étudiée il y a longtemps, est un prérequis de la connaissance actuelle, produit régulièrement des erreurs, ou a simplement été choisie aléatoirement.

## 16. Sélection des connaissances

La sélection doit être suffisamment flexible pour éviter deux extrêmes :

- **Sous-révision** — les connaissances anciennes disparaissent progressivement du processus, au profit des nouvelles.
- **Sur-révision** — une connaissance stable est répétée excessivement au détriment de nouvelles connaissances.

MC-006 doit donc chercher un équilibre dynamique entre acquisition de nouvelles connaissances et maintien des connaissances précédentes.

## 17. Récupération et réactivation

La consolidation est renforcée lorsque l'apprenant doit récupérer une connaissance plutôt que simplement la reconnaître :

```
Reconnaissance → Rappel avec support → Rappel sans support → Production autonome → Production spontanée
```

MC-006 peut utiliser ces différents niveaux selon la connaissance et son historique. La réactivation ne doit donc pas toujours présenter immédiatement la réponse ou la règle.

## 18. Réutilisation dans de nouveaux contextes

Une connaissance répétée uniquement dans son contexte original peut donner une impression de maîtrise sans garantir sa flexibilité. MC-006 doit donc favoriser, lorsque cela est pertinent : nouveaux sujets, nouveaux exemples, nouveaux contextes, nouvelles combinaisons, nouvelles tâches, nouvelles transformations, nouvelles interactions.

Le principe est : réactiver la connaissance sans nécessairement reproduire exactement l'expérience initiale.

## 19. Interaction avec MC-001

MC-001 définit la structure de la leçon. MC-006 peut fournir du contenu de consolidation à différents moments de cette structure :

```
Nouvelle leçon → Contenu nouveau → Pratique → Transformation → MC-006 → Réactivation d'une connaissance antérieure
```

La consolidation continue ne constitue donc pas nécessairement une activité séparée. Elle peut être intégrée aux leçons quotidiennes.

## 20. Interaction avec MC-002

MC-002 constitue la source principale d'information concernant l'état des connaissances. La relation est cyclique :

```
MC-002 (état/évidence) → MC-006 (sélection) → réactivation → nouvelle production → MC-002
```

MC-006 ne détermine donc pas seul qu'une connaissance est maîtrisée ou non. Il fournit une nouvelle occasion d'observer cette connaissance.

## 21. Interaction avec MC-004

MC-004 définit la consolidation par transformation. Une transformation déjà utilisée peut être sélectionnée ultérieurement par MC-006 afin de vérifier si la relation structurelle reste accessible dans le temps.

```
MC-004 (transformation A→B, utilisation initiale) → MC-006 (réactivation ultérieure) → nouvelle transformation → MC-002
```

**MC-004 fournit le mécanisme de transformation ; MC-006 peut décider de le réintroduire dans le temps.** MC-006 ne redéfinit donc pas les transformations.

## 22. Interaction avec MC-005

MC-005 gère le vocabulaire. Lorsqu'un élément lexical nécessite une réactivation, MC-005 peut fournir l'information nécessaire à MC-006 :

```
MC-005 (élément lexical à réactiver) → MC-006 (sélection/espacement) → réutilisation → MC-002 (observation)
```

**MC-005 gère le contenu lexical ; MC-006 gère sa consolidation continue.**

## 23. Indépendance linguistique

MC-006 doit être indépendant de toute langue particulière. Il ne doit donc pas contenir de liste de temps verbaux, de catégories grammaticales propres au français, de règles propres au coréen, de listes lexicales, ni de structures phonologiques spécifiques. Il travaille exclusivement avec des références vers les architectures linguistiques :

```
MC-006 → FR-*, KO-*, EN-* → connaissances à réactiver
```

Les paramètres nécessaires à une langue particulière doivent être définis dans son architecture ou dans les futurs mécanismes prévus par LG-000.

## 24. La roulette comme implémentation

La roulette virtuelle utilisée initialement pour les temps verbaux constitue une implémentation concrète de la Révision par hasard — elle ne constitue pas MC-006 lui-même.

```
Grammar of the day → Writing → Corrections → Transformations → 🎲 → sélection aléatoire
→ connaissance antérieure → nouvelle mobilisation
```

La roulette peut donc être utilisée comme interface ou mécanisme de sélection, mais le système doit rester fonctionnel même si aucune roulette n'est disponible. Cela garantit que la méthode survit à l'implémentation. Une application future pourrait remplacer la roulette par un algorithme de sélection, une file de priorités, un système adaptatif, un générateur pseudo-aléatoire, ou une combinaison de plusieurs critères — le principe méthodologique reste identique.

## 25. Limites et garde-fous

La consolidation continue ne doit pas devenir une répétition permanente. MC-006 doit éviter :

- **25.1 La répétition mécanique** — une connaissance ne doit pas être répétée exactement sous la même forme indéfiniment.
- **25.2 La surcharge** — le nombre de connaissances réactivées doit rester compatible avec la charge cognitive de la séance.
- **25.3 La monopolisation par les erreurs** — une difficulté persistante peut augmenter la priorité d'une connaissance, mais ne doit pas nécessairement monopoliser toutes les séances.
- **25.4 La révision sans objectif** — chaque réactivation doit avoir une justification pédagogique identifiable (hasard, dépendance, erreur, temps, ou une combinaison).
- **25.5 La régression artificielle** — une erreur ponctuelle ne doit pas provoquer automatiquement une répétition intensive.

## 26. Principe de non-régression

MC-006 applique le principe de non-régression défini par MC-002. Exemple : *10 observations, 9 correctes, 1 erreur* ne doit pas être interprété de la même manière que *10 observations, 4 correctes, 6 erreurs similaires*.

MC-006 utilise donc l'historique fourni par MC-002 au lieu de considérer chaque erreur comme une remise à zéro.

## 27. Historique de consolidation

Les événements significatifs de consolidation doivent pouvoir être représentés dans le temps. Exemple :

```
FR-531
10/08 → En cours d'acquisition
15/08 → Acquis
22/08 → Consolidé
05/09 → Réactivation
12/09 → Production correcte
```

L'historique permet de distinguer première acquisition, réactivation, nouvelle observation, stabilité, difficulté, et retour à la consolidation. MC-006 exploite cet historique pour améliorer la sélection future.

## 28. Architecture du cycle continu

```
NOUVELLE CONNAISSANCE → MC-001 → APPRENTISSAGE → MC-002 → ÉTAT DE LA CONNAISSANCE
→ [CONNAISSANCE DISPONIBLE + HISTORIQUE] → MC-006
→ [hasard, dépendance, erreurs, temporelle] → SÉLECTION → RÉACTIVATION
→ NOUVELLE MOBILISATION → MC-002 → NOUVELLE ÉVIDENCE → (retour à MC-006)
```

La boucle est donc continue.

## 32. Glossaire

| Terme | Définition |
|---|---|
| Consolidation continue | Processus permanent de maintien, récupération et remobilisation des connaissances précédemment étudiées. |
| Réactivation | Nouvelle mobilisation d'une connaissance déjà étudiée. |
| Récupération | Action de retrouver une connaissance en mémoire afin de l'utiliser. |
| Révision par hasard | Sélection non déterministe d'une connaissance précédemment étudiée. |
| Révision par dépendance | Sélection d'une connaissance en fonction de sa relation avec une autre connaissance actuellement mobilisée. |
| Révision par erreurs fréquentes | Sélection fondée sur la récurrence d'une difficulté observée dans les productions de l'apprenant. |
| Révision temporelle | Sélection fondée notamment sur le temps écoulé depuis la dernière mobilisation significative. |
| Roulette | Implémentation possible de la révision par hasard. |
| Connaissance antérieure | Connaissance ayant déjà été introduite dans le parcours d'apprentissage. |
| Mobilisation | Utilisation effective d'une connaissance dans une tâche ou une production. |
| Réutilisation | Nouvelle utilisation d'une connaissance dans un contexte différent ou ultérieur. |
| Historique | Ensemble des observations et événements pédagogiques associés à une connaissance. |
| Priorité de réactivation | Importance relative accordée à une connaissance lors de la sélection des éléments à consolider. |
| Architecture linguistique | Organisation déclarative des connaissances propres à une langue. |
