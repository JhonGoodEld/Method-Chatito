## Objectif

Le domaine FR-500 regroupe l'ensemble des connaissances **déclaratives** relatives au système verbal français : ce qui existe dans le système, non la manière dont on l'apprend ou dont on s'exerce à l'utiliser.

Ce domaine applique le Principe 8 de MC-000 (séparation déclaratif/procédural) : « *être* » est une connaissance, « *conjuguer être* » est un procédé — le premier appartient à FR-500, le second exclusivement à MC-001. Voir MC-000, Principe 8, pour la formulation complète du principe.

Le système verbal constitue, avec le système nominal, l'un des deux piliers fondamentaux de la grammaire française.

## Position dans le système

Français → FR-100 Phonologie, FR-200 Orthographe, FR-300 Lexique, FR-400 Système nominal, **FR-500 Système verbal**.

### FR-530 — Les modes

**Question :** Quels modes verbaux existent et comment se structurent-ils ?

**Contenu :** Indicatif, Subjonctif, Conditionnel, Impératif, Infinitif, Participe, Gérondif.

> **Principe architectural :** les modes sont **polymorphes**. Chaque mode définit sa propre structure interne, sans qu'une symétrie soit imposée entre eux. FR-530 n'est pas une hiérarchie rigide mais un conteneur de systèmes hétérogènes :
> - **Indicatif, Subjonctif, Conditionnel** → Temps simples / Temps composés
> - **Impératif** → Présent uniquement (le passé, rare et littéraire, est documenté comme cas particulier)
> - **Infinitif** → Présent / Passé
> - **Participe** → Présent / Passé (le participe passé assume en outre un rôle transversal : il est l'élément constitutif des temps composés de tous les autres modes)
> - **Gérondif** → Présent uniquement (le gérondif passé, marginal, est documenté comme cas particulier)

### FR-540 — Les temps

Les temps n'existent pas comme catégorie indépendante : ils sont une propriété de chaque mode et se trouvent donc **imbriqués dans FR-530**, selon la structure polymorphe décrite ci-dessus. Exemples de chemins :

- Indicatif → Temps simples → Présent
- Indicatif → Temps composés → Plus-que-parfait
- Subjonctif → Temps simples → Présent
- Infinitif → Passé

### FR-550 — Les constructions verbales

**Question :** Quelles constructions le verbe peut-il former ?

**Contenu :**
- Voix active
- Voix passive
- Verbes pronominaux
- Verbes impersonnels
- Périphrases
- Verbes à préposition

> **Note :** cette branche décrit uniquement la **construction syntaxique** (ex. : *Verbe + Préposition + Complément*). Le lexique précis — quelle préposition suit quel verbe (*penser à*, *renoncer à*, *tenir à*) — est stocké comme collocation dans FR-340 (Lexique). Même règle de frontière que celle déjà appliquée dans FR-400.

### FR-560 — Les relations temporelles

**Question :** Comment les temps se relient-ils entre eux ?

**Contenu :**
- Concordance des temps
- Discours indirect
- Enchaînement temporel
- Antériorité
- Simultanéité
- Postériorité

Ce sous-domaine ne décrit pas un temps isolé, mais les **relations entre temps** — la logique qui détermine, par exemple, pourquoi un temps précède ou dépend d'un autre dans un même énoncé.

### FR-570 — Les emplois du verbe

**Question :** Pourquoi choisit-on un temps plutôt qu'un autre ?

**Contenu :**
- Aspect
- Valeurs des temps
- Nuances
- Registre
- Choix du temps

Couche sémantique : pourquoi tel temps est choisi plutôt qu'un autre dans un contexte donné (ex. : imparfait vs passé composé).
